## 📂 Projects

### 📝 Notes App

A responsive notes application built with React and Tailwind CSS.

#### Features
- Create notes with title and details
- Display recent notes
- New notes appear at the top
- Delete notes
- Responsive layout
- Sticky-note style UI
- Handles long text without overflowing

#### React Concepts Practiced
- `useState`
- Controlled components
- Form handling
- Event handling
- Array manipulation
- `.map()`
- Conditional rendering
